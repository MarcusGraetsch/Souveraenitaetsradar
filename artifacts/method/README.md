# Methoden-Workbook

Das vollständige Excel-Arbeitsmodell **Souveraenitaets-Radar_Methodenmodell_v0.9.xlsx** ist das historische/analytische Arbeitsartefakt der bisherigen Entwicklung.

Für Agenten und Versionskontrolle werden die fachlich relevanten Tabellen in diesem Repository unter `data/method/` als UTF-8-CSV geführt. Regeln und Entscheidungen liegen zusätzlich unter `config/`, `project/` und `docs/`.

Das binäre Workbook soll als versioniertes Release-/Projektartefakt abgelegt werden, nicht als einzige maschinenlesbare Source of Truth. Bis zur Einrichtung eines passenden Binary-/Release-Workflows ist es außerhalb des Git-Textbestands aufzubewahren.
