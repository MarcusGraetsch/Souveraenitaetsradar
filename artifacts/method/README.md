# Method Workbook

Das Methodenmodell wurde im Arbeitsprozess als `Souveraenitaets-Radar_Methodenmodell_v1.0.xlsx` erzeugt. Das Repository behandelt das binäre Workbook **nicht als Source of Truth**.

Für Agenten und Software liegen die kanonischen Inhalte als CSV/YAML/JSON/Markdown unter `data/method/`, `config/`, `schemas/` und `docs/`. Das SHA-256-/Sheet-Manifest des erzeugten Workbooks steht in `METHOD_WORKBOOK_MANIFEST.md`.

Bei Bedarf kann das XLSX als Release-/Projektartefakt separat abgelegt werden, ohne die Agentenarbeit davon abhängig zu machen.
