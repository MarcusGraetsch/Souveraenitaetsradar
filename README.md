# Souveränitätsradar

Arbeitsrepository für die Entwicklung einer belastbaren Methode und eines späteren Tools zur Bewertung digitaler Souveränitätsrisiken von Cloud-, Plattform- und KI-Lösungen.

> Dieses Repository wird gerade initialisiert. Die vollständige Projektstruktur, Methodik, Agentenregeln und bisherigen Artefakte werden in einem Bootstrap-Branch eingebracht und anschließend per Pull Request geprüft.
