# Agent Session Logs

Jede substanzielle Agentensitzung erhält eine eigene Datei:

`YYYY-MM-DD_<topic>.md`

Mindestinhalt:

- Aufgabe / Rolle
- gelesene Kernquellen
- Änderungen
- Tests / Review
- Entscheidungen / Annahmen
- offene Punkte
- empfohlener nächster Schritt

Session Logs sind **kein Ersatz** für `PROJECT_STATE.yaml`, ADRs oder akzeptierte Decisions. Sie dienen der Übergabe und Nachvollziehbarkeit.
