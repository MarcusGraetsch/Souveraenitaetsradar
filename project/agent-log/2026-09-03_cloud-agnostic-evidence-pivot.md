# Agent Log – Cloud-agnostic Evidence Pivot

Date: 2026-09-03
Role: architect / methodologist / project-coordinator

## Trigger

The planned consultant-operated AWS Bedrock collector was challenged as unrealistic for customer engagements because customers are unlikely to provide root/admin/account credentials and the approach would overfit the method to one hyperscaler.

## Decisions

- direct customer cloud access is not a standard requirement
- customer-mediated Evidence Pack becomes the default intake
- cloud-specific exports are generated by the customer if desired
- provider adapters map provider-specific evidence to generic facts/capabilities
- core rule engine remains provider-neutral
- old AWS collector direction is archived/superseded

## Changes

- project state/roadmap/next actions revised
- evidence acquisition architecture redesigned
- evidence pack schema/template/validator added
- provider adapter interface added
- active AWS collector removed from tool path
- historical R5/R6 material retained for traceability

## Next

Pilot the generic Evidence Pack and connect evidence records to claims and hard gates.
