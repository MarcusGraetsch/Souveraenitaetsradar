# NEXT-118 Hard-Gate-Terminologie – Umsetzungshinweise

- Primäre UI-Begriffe deutsch und selbsterklärend.
- Interne Codes/Methodennamen sekundär/auditierbar erhalten.
- Keine Änderung der deterministischen Gate-Logik.
- Acht Gate-Namen auf deutsch primär anzeigen.
- Status `PASS/FAIL/UNVERIFIED/N/A` auf deutsch labeln, interne Codes sekundär.
- `Req/Cap/Trust` durch ausgeschriebene Begriffe mit kurzen Hilfetexten ersetzen.
- Claim-Formular auf `Geprüfte Feststellungen` umstellen.
- Evidence Requests deutsch anzeigen.
- `Requirement 0–4` nicht als nackte Zahl ohne Erklärung darstellen; die vorhandene interne Skala muss vor UI-Labeling fachlich dokumentiert werden, ohne neue Normbedeutung zu erfinden.
