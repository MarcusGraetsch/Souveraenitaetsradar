# NEXT action ↔ GitHub issue mapping

This file is intentionally lightweight. The authoritative prioritization remains `project/NEXT_ACTIONS.yaml`; GitHub Issues are the operational execution queue.

When creating an issue from a `NEXT-*` item, preserve the `NEXT-*` ID in the issue title. Do not silently change priority or scope in the issue without updating `NEXT_ACTIONS.yaml` in the same reviewed change.
