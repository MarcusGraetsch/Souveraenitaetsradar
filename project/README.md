# Project coordination files

Read in this order after `AGENTS.md`:

1. `PROJECT_STATE.yaml` — current accepted project state
2. `HANDOFF.md` — compact handoff for the next contributor/agent
3. `NEXT_ACTIONS.yaml` — prioritized backlog and dependencies
4. `DECISIONS.yaml` — accepted project decisions
5. `ROADMAP.md` and `WORK_BREAKDOWN.md` — planning context
6. `agent-log/` — chronological implementation/research notes

GitHub Issues are the operational work queue. IDs such as `NEXT-101` are preserved in issue titles so repository state and issue tracking can be correlated.
