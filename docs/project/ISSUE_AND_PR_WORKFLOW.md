# Issue- und PR-Workflow

## Issue

Für substanzielle Arbeit:

- Problem / Ziel
- Scope / Non-Scope
- Akzeptanzkriterien
- Quellen-/Evidence-Bedarf
- Risiken / Abhängigkeiten

## Branch

Ein Branch pro zusammenhängendem Arbeitsgegenstand.

## PR

PR enthält:

- Was / warum
- Änderungen
- Provenienz
- Tests
- Risiken
- Handoff

## Merge

Bevorzugt squash, wenn keine historische Mehrcommit-Struktur benötigt wird. Nach Merge Next Actions/Issues nachziehen.
