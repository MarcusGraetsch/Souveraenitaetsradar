# Definition of Done

Eine Änderung ist „done“, wenn soweit anwendbar:

- fachlicher Zweck erfüllt
- Provenienz/Source IDs ergänzt
- externe vs. interne Regel klar getrennt
- Tests vorhanden und erfolgreich
- keine Secrets/Kundendaten enthalten
- Docs/Schemas aktualisiert
- Rückwärtskompatibilität betrachtet
- Reviewer-Kommentare erledigt
- `PROJECT_STATE`/`HANDOFF` nur bei tatsächlicher Zustandsänderung angepasst
- neuer offener Folgepunkt als Issue/Next Action dokumentiert
