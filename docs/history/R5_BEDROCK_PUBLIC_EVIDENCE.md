# R5 Bedrock Public Evidence – retained provider example

Amazon Bedrock was used as the first real public-evidence case because it exposed important method issues:

- legal entity and effective control are distinct
- data residency can depend on model/inference mode
- customer-managed keys do not automatically equal provider-independent key control
- logging can improve evidence while increasing data persistence
- managed AI guardrails do not necessarily cover all agent/tool execution paths
- a compliance scope page is not identical to a current independent attestation for a newer framework version

This research remains a regression/example dataset. It does **not** define the cloud-agnostic architecture.
