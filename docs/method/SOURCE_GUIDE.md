# Source Guide

Das vollständige Source Register liegt in `data/method/source_register.csv`.

## Wichtige Quellenfamilien

- BSI Standard 200-3 und IT-Grundschutz-Kompendium
- EU Cloud Sovereignty Framework + Implementation Guidance
- BSI C3A und C5
- NIS2 + Durchführungsverordnung 2024/2690 + ENISA Guidance
- DORA + technische Standards/Informationsregister
- ISO/IEC 27005 / ISO 31000 / IEC 31010
- NIST SP 800-30 und Supply-Chain-Risk-Management-Referenzen
- Data Act Switching / Interoperability
- EDPB Transfer-Assessment-Guidance
- KI-spezifische BSI-/EU-Quellen
- Provider-Primärdokumentation für Evidence Pilots

## Regel

Vor einer kundenseitigen Aussage immer prüfen:

1. Quelle aktuell?
2. richtige Version?
3. richtige Service-/Region-/Model-Scope?
4. direkte Quelle oder eigene Ableitung?
5. ist ein Vertrag/Test/Attest statt Provider-Selbstauskunft erforderlich?
