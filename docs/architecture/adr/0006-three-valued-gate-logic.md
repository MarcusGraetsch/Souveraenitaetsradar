# ADR 0006 – PASS/FAIL/UNVERIFIED

**Status:** Accepted  
**Datum:** 2026-09-03

## Entscheidung

Fehlende Evidence erzeugt UNVERIFIED statt automatischem FAIL/PASS.

## Begründung

Reduziert Scheingenauigkeit und trennt Nichtwissen von negativer Beobachtung.

## Konsequenzen

Änderungen an diesem Prinzip benötigen einen neuen ADR oder eine explizite Ablösung dieses ADRs.
