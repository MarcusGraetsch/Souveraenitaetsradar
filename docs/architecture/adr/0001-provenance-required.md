# ADR 0001 – Provenienz ist Pflicht

**Status:** Accepted  
**Datum:** 2026-09-03

## Entscheidung

Jede fachliche Regel, Frage, Schwelle und Evidence-Aussage muss Quelle oder interne Herkunft ausweisen.

## Begründung

Verhindert Quellenwäsche und macht Management-Erklärbarkeit möglich.

## Konsequenzen

Änderungen an diesem Prinzip benötigen einen neuen ADR oder eine explizite Ablösung dieses ADRs.
