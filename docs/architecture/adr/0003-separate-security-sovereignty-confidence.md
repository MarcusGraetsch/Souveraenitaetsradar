# ADR 0003 – Security, Souveränität und Confidence bleiben getrennt

**Status:** Accepted  
**Datum:** 2026-09-03

## Entscheidung

Mindestens Security/Operational Risk, Sovereignty Capability/Risk und Evidence Confidence werden separat dargestellt.

## Begründung

Die R3-Szenarien zeigen gegenläufige Profile.

## Konsequenzen

Änderungen an diesem Prinzip benötigen einen neuen ADR oder eine explizite Ablösung dieses ADRs.
