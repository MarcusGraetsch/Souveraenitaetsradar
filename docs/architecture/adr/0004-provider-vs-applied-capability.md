# ADR 0004 – Provider Capability ≠ Applied Capability

**Status:** Accepted  
**Datum:** 2026-09-03

## Entscheidung

Fähigkeiten werden nach available/selected/configured/tested/attested unterschieden.

## Begründung

Providerdokumentation allein belegt keine Kundenkonfiguration.

## Konsequenzen

Änderungen an diesem Prinzip benötigen einen neuen ADR oder eine explizite Ablösung dieses ADRs.
