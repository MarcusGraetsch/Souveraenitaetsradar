# ADR 0002 – Gate first, score second

**Status:** Accepted  
**Datum:** 2026-09-03

## Entscheidung

Hard Gates werden vor gewichteten Vergleichsindizes ausgewertet.

## Begründung

Nicht kompensierbare Mindestanforderungen dürfen nicht durch andere Stärken verschwinden.

## Konsequenzen

Änderungen an diesem Prinzip benötigen einen neuen ADR oder eine explizite Ablösung dieses ADRs.
