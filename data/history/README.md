# Historical Method Data

Provider-specific pilot history is kept as narrative, provenance-safe documentation under `docs/history/` and through the Source Register. Historical CSV snapshots are intentionally not part of the active machine-readable method surface because their provider-specific fields must not be mistaken for current generic schemas.

See:

- `docs/history/R5_BEDROCK_PUBLIC_EVIDENCE.md`
- `docs/history/R6_AWS_COLLECTOR_APPROACH_RETIRED.md`
- `data/method/source_register.csv`
